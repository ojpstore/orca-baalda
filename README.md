# Baalda Notes (Orca plugin)

Orca 사이드바에서 Baalda 볼트의 노트를 보고, 편집하고, 새로 만듭니다.

## 기능

### 패널

- 볼트 목록: `%APPDATA%\com.baalda.context\config.json`의 최근 볼트 (`.context` 폴더가 있는 것만)
- 볼트 경로: 패널 맨 위에 표시. 버튼으로 `.context`가 있는 아무 볼트 폴더나 추가(플러그인 저장소에 기억)
- 트리: Baalda 스타일(폴더 색 박스, sync 점). 폴더 색은 Baalda가 저장하지 않아 경로 해시로 배정
- 조작: 폴더는 클릭으로 펼치기/접기, 노트는 클릭으로 선택하고 더블클릭 또는 Enter로 열기.
  ↑/↓ 이동, `B` 즐겨찾기, `F2` 이름 변경, `Delete` 삭제. 모두 접기/펼치기 버튼
- 검색: 이름은 입력 즉시, 본문은 입력이 멈추면(0.25초) 워커가 검색. 일치 부분 강조, Esc로 지우기
- 탭: NOTES / 즐겨찾기(별표한 노트만, 볼트별 저장). 각 노트 오른쪽 별로 추가·해제
- 새 노트·새 폴더·이름 변경·이동: 선택한 폴더(또는 선택한 노트의 폴더) 안에 생성, `F2` 또는 버튼으로 이름 변경, 트리 내 드래그 앤 드롭으로 폴더 이동(즐겨찾기·펼침 상태 자동 갱신)
- 삭제: 노트·폴더 모두 확인 창을 거쳐 휴지통으로 이동(Windows)
- 잠금: 체크하면 그 볼트는 읽기 전용. 에디터의 편집 버튼이 사라지고(편집 중이면 저장 후 보기로),
  패널의 새 노트·새 폴더·삭제가 비활성화. 볼트별로 저장
- 드래그: 노트/폴더 행을 Orca 터미널로 끌어 놓으면 절대 경로가 붙여넣어짐
- 볼트·펼친 폴더·선택·탭 상태는 다시 열어도 유지

### 에디터

- 노트 열기: **현재 활성 워크스페이스**의 Baalda 탭 하나에 표시. 워커가 `<워크스페이스>/.orca/baalda/Baalda.baalda`
  (자체 `.gitignore`로 git에서 제외, 활성 워크스페이스가 없으면 `~/.orca/baalda/`)에 `{vault, path}`를 쓰고 그 파일을 Baalda 에디터로 연다
  (이미 열려 있으면 같은 탭). 편집은 자동 저장(0.8초) + Ctrl+S. `.orca/`는 dev 플러그인 감시에서도 제외됨
- 링크·탐색: `[[경로|별칭]]`, 상대 `.md` 링크 클릭 시 같은 탭에서 이동(볼트 경로 → 상대 경로 → 이름 순으로 찾음).
  헤더의 `←`/`→` 버튼 또는 `Alt+←`/`Alt+→`로 뒤로/앞으로 이동.
  `.html` 페이지(대시보드)는 sandbox iframe으로 렌더링하고, Baalda SDK(`baalda.app.open`) 대체 스크립트를 넣어
  대시보드의 버튼·링크도 노트 이동으로 연결. 이동하면 패널도 그 노트를 선택하고 폴더를 펼침
- 보기·충돌 보호: 보기 모드에서 마크다운 체크리스트(`- [ ]`)를 클릭해 바로 토글·저장(잠금 볼트 제외). 편집 중 외부에서 파일이 변경되면 상단 배너로 알림(다시 불러오기 / 내 내용 유지)
- 편집 툴바: 제목(H1~H3), 굵게(Ctrl+B)·기울임(Ctrl+I)·취소선·인라인 코드·링크(Ctrl+K),
  목록·번호 목록·체크리스트·인용, 코드 블록·표·구분선, 이모지(한국어 검색)
- 입력 편의(편집 모드):
  - `Tab`/`Shift+Tab`: 선택한 줄 들여쓰기/내어쓰기(4칸). 목록이 아닌 줄에서 `Tab`만 누르면 공백 4칸
  - 목록 이어쓰기: `-`, `*`, `+`, `1.`, `- [ ]` 항목에서 `Enter` 시 다음 항목 자동 생성(번호 증가, 체크박스는 빈 상태).
    빈 항목에서 `Enter`를 누르면 목록 종료. 코드 블록 안, `Shift+Enter`, 한글 IME 조합 중에는 동작하지 않음
  - `[[` 자동완성: 볼트 노트 목록 팝업(이름 우선 정렬, ↑/↓, `Enter`/`Tab`/클릭으로 선택, `Esc` 닫기).
    선택하면 `[[경로]]` 삽입(`.md`는 생략). 팝업은 캐럿이 아니라 툴바 아래 고정 위치에 표시
- 이미지:
  - 보기 모드에서 `![](상대경로)`, `![[파일.png]]`를 워커(`note.image`)가 읽어 표시(png/jpg/gif/webp/bmp, 10MB 이하).
    노트 기준 상대 경로 → 볼트 기준 경로 → 파일 이름 순으로 찾음. 볼트 밖 경로, 점 폴더(`.context` 등),
    볼트 밖을 가리키는 심볼릭 링크, 이미지가 아닌 파일은 거부. 웹(`http(s)`) 이미지는 그대로 로드
  - 편집 모드에서 `Ctrl+V`로 클립보드 이미지를 붙여넣으면 볼트의 `attachments/image-<시각>.<확장자>`에 저장하고
    노트 기준 상대 경로 링크 `![](...)`를 커서에 삽입(`note.attach`, 64KB 제한 때문에 base64를 나눠 전송).
    잠긴 볼트는 거부. 클립보드에 텍스트가 함께 있으면 일반 붙여넣기. 비어 있는 `attachments/` 폴더는 트리에서 숨김
- 백링크: 에디터 하단 접이식 "백링크 (n)" 영역에 이 노트를 `[[...]]` 또는 상대 링크로 참조하는 노트 목록
  (`note.backlinks`, 이미지·웹 링크 제외). 클릭하면 그 노트로 이동. 노트를 열 때와 외부 변경 시 갱신
  (편집 중에는 자동저장마다 볼트를 다시 읽지 않도록 갱신하지 않음). 요청마다 전체 문서를 읽으므로
  노트가 수천 개를 넘으면 인덱스 필요, 코드 블록 안의 링크도 포함됨
- 긴 노트는 Orca 요청 크기 제한(약 64KB) 때문에 나눠서 저장
- 읽기 버튼: 워커가 Windows 한국어 음성(`System.Speech`)으로 노트 본문을 읽음(에디터 프레임이 아니라 워커라서 Orca 탭을 바꿔도 안 멈춤). 노트·탭·모드를 바꿔도 계속되고 정지 버튼으로만 멈춤(끝까지 읽으면 처음부터 반복)
- 맨 위로 버튼, 테마에 맞춘 스크롤바

### 동기화·보안

- Baalda는 local-first라 데스크톱 앱이 볼트 파일 변경을 서버와 동기화합니다.
  패널은 `.context/config.json`으로 노트별 sync 상태(`대기` 표시)를 보여줌
- 구름 버튼: Baalda 앱이 꺼져 있으면 창 없이 실행해 업로드하고, 끝나면 종료. 진행 중에는 버튼 비활성화,
  상태 줄에 서버 주소 표시. 바로가기 버튼으로 Baalda 앱 창 열기
- 디스크 변경은 `fs.watch`로 자동 반영
- 볼트 밖 경로는 워커가 거부(노트·이미지 모두). 잠긴 볼트는 이미지 붙여넣기도 워커에서 거부

## 개발

```sh
npm i                    # typescript, @types/node (타입체크용)
npx tsc -p .
orca plugin test .       # 주의: 플러그인이 Orca 설치 드라이브(C:)와 다른 드라이브에 있으면
orca plugin check .      # 테스트 런타임을 못 찾음 → C: 아래로 복사해서 실행
orca plugin dev load . --approve <fingerprint>
node editor/vendor/emoji.gen.mjs  # 이모지 데이터(emojibase-data, 한국어) 재생성
```
